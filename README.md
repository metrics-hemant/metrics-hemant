# Summer Olympic Medals Analysis (1976–2016)

## Overview

This project is an end to end data analysis of the **Summer Olympic Medals dataset (1976–2016)**. Using Python, I cleaned, explored, and visualized historical Olympic medal data to identify trends in athlete performance, country dominance, gender participation, and sport wise achievements.

The project demonstrates the complete data analysis workflow, from raw data preprocessing to extracting meaningful business style insights through visualizations.

---

## Dataset

**Dataset Name:** Summer Olympic Medals (1976–2016)

### Features

* City
* Year
* Sport
* Event
* Athlete
* Gender
* Country Code
* Country Name
* Medal

The dataset contains medal winning athletes across multiple Summer Olympic Games from **1976 to 2016**.

## Project Objectives

* Clean and prepare the raw Olympic dataset
